# Claude-Chat-Scheduler
Browser extension to schedule your claude chats that may pause to 5 hour limit and go to sleep.
<img width="399" height="535" alt="image" src="https://github.com/user-attachments/assets/e32fc444-4a39-4ca1-9d5f-a7081e4944c9" />

Tired of waiting for 5 hours to start a new chat or resume existing one? This browser extension allows you to schedule your chat. It will automatically open URL in new tab, adds the message you to add and simulate a click to make your claude running. Enjoy and go to sleep.

## Steps to Run.
1. Turn on developer mode for browser in extensions.
2. Load Unpacked, and select this extension folder.
3. It will show in your browser.
4. Schedule and enjoy!!!
5. Make sure to set two or three minutes ahead of your reset limit plz.
